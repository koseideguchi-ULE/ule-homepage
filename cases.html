スタートアップ企業

スタートアップ企業のバックオフィス立ち上げ

0→1の体制構築から実務運用までを一気通貫で支援

課題

事業の立ち上げ期において、バックオフィスの仕組み（規程やフロー）が未整備。
「誰に・何を・どう指示するか」を考えるマネジメントコストや、教育にかける時間がない。

解決策

  • ✓ 立ち上げから運用まで伴走: 業務フローの整理・設計、就業規則や各種規程の整備、社内ポータル（SharePoint等）の構築を実施
  • ✓ 専門チームによる対応: 労務や秘書業務など、各分野の専門性を持ったメンバーがチームでバックアップする体制を提供

成果

仕組みを作るだけでなく、実際に業務が回る実務運用まで定着。
経営者や社員が本来注力すべき事業に集中できる環境を実現。

大学研究室

大学研究室（公的資金・大型補助金プロジェクト）

複雑な事務処理と経費管理の適正化

業種・規模

京都大学 学術変革領域(A) 事務局 / AMED・NEDO採択プロジェクト

課題

大型の国の補助金（AMED, NEDO等）は、採択後の事務処理や経費管理が非常に煩雑。
直接経費・間接経費の整理や証憑書類の管理に手間がかかり、研究時間が圧迫される。

解決策

  • ✓ 補助金採択後支援: 機構のマニュアルに沿った確実な事務局対応と経費管理を実行
  • ✓ 報告書作成補助: 証憑書類の整理から実績報告書の提出までをサポート

成果

厳格なルールが求められる公的資金の管理において、不備のない適正な運用を実現。
研究者が「本来やるべき学術的な活動」に専念できる環境を確保。

学会・国際会議

国際会議・学術集会

準備から当日運営まで、バイリンガル対応を含む事務局運営

業種・規模

早稲田大学 国際会議、WEPA 2019 / DS 2017 等

課題

国際会議における海外参加者への対応や登録管理など、専門的な事務局機能が必要。
主催者や運営委員会との調整業務が多岐にわたり、準備の負担が大きい。

解決策

  • ✓ ワンストップ運営支援: 参加者登録管理、海外参加者対応、当日の運営補助までを一貫して担当
  • ✓ 柔軟な体制: 準備段階から当日まで、フェーズごとの業務量に応じたサポートを提供

成果

円滑な会議運営と、海外ゲストへの適切な対応を実現。
主催の研究者が運営実務から解放され、会議の中身（学術交流）に集中可能に。

イノベーション創出事業

イノベーション創出事業・採択企業

国の推進事業における事務局機能のアウトソーシング

業種・規模

文部科学省 中小企業イノベーション創出推進事業 採択企業

課題

国の推進事業に採択されたものの、社内に対応できる事務局ノウハウやリソースが不足している。
プロジェクト期間中の報告業務や事務連絡が負担となっている。

解決策

  • ✓ 事務局支援: 事業の要件を理解した上で、必要な事務局機能を代行・支援
  • ✓ 業務単位の請負: 人の雇用ではなく「業務」として依頼を受けることで、繁閑に合わせた柔軟な運用が可能

成果

事業推進に必要な事務要件を確実にクリアし、プロジェクトの円滑な進行をサポート。
指示・教育不要で、即戦力の事務局機能を獲得。
