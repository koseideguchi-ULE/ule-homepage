# Unlimited Energy Website

アンリミティッドエナジー合同会社の公式ウェブサイト

## 概要

バックオフィス支援、補助金・研究費支援、学会運営支援、人材マッチング支援を提供する企業のウェブサイトです。

## 主な機能

- ✨ モダンなダークグラデーションデザイン（Synthesy参考）
- 📧 Google Sheets連携のお問い合わせフォーム
- 📨 自動メール通知機能
- 📱 レスポンシブデザイン

## 技術スタック

- HTML5
- CSS3（カスタムプロパティ使用）
- JavaScript（Vanilla JS）
- Google Apps Script（バックエンド）

## デザインの特徴

- ブルー・ネイビーカラーテーマ
- ピル型ボタン
- グラデーションとグロー効果
- ミニマルでモダンなレイアウト

## セットアップ

### ローカル環境

1. リポジトリをクローン
2. HTMLファイルをブラウザで開く

### お問い合わせフォーム設定

詳細は `SETUP_GUIDE.md` を参照してください。

## ファイル構成

```
├── index.html          # トップページ
├── about.html          # 会社情報
├── services.html       # サービス紹介
├── cases.html          # 導入事例
├── faq.html            # よくある質問
├── contact.html        # お問い合わせ
├── styles.css          # メインスタイル
├── styles-extra.css    # 追加スタイル
├── script.js           # JavaScript
└── google-apps-script.js  # Google Apps Script
```
