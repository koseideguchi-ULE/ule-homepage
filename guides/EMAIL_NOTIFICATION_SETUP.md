# メール通知機能セットアップ手順

## 📧 概要
お問い合わせフォームからデータが送信されると、Googleスプレッドシートへの保存と同時に、指定したメールアドレスに自動通知が送信されます。

## ✨ メール通知の特徴

### 📱 見やすいHTMLフォーマット
- ネイビーのグラデーションヘッダー
- アイコン付きの項目ラベル
- 構造化されたレイアウト
- メールアドレスはクリック可能なリンク
- レスポンシブデザイン

### 📋 含まれる情報
- 📅 受信日時
- 🏢 会社名・所属
- 👤 お名前
- 📧 メールアドレス（クリックでメール作成）
- 📞 電話番号
- 📁 カテゴリー（日本語表記）
- 💬 お問い合わせ内容

### ✉️ メール件名
`【お問い合わせ受付】会社名 お名前様より`

## 🔧 セットアップ手順

### ステップ1: メール通知先の設定
1. Google Apps Scriptエディタを開く
2. コード17行目の`NOTIFICATION_EMAIL`を確認：
   ```javascript
   const NOTIFICATION_EMAIL = 'kaori.deguchi@unlimitedenergy.co.jp';
   ```
3. 必要に応じてメールアドレスを変更
4. 「プロジェクトを保存」をクリック

### ステップ2: スクリプトの再デプロイ
**既存のデプロイを更新する方法:**

1. Apps Scriptエディタで「デプロイ」→「デプロイを管理」をクリック
2. 既存のデプロイの右側にある鉛筆アイコン（編集）をクリック
3. 「新しいバージョン」を選択
4. 「デプロイ」をクリック
5. デプロイURLは変更されないため、ウェブサイトの修正は不要です

### ステップ3: テスト送信
1. ウェブサイトのお問い合わせフォームからテスト送信
2. 数秒後に設定したメールアドレスに通知が届くことを確認
3. HTMLメールが正しく表示されることを確認

## ⚙️ カスタマイズオプション

### メール通知先を追加する場合
複数のメールアドレスに送信したい場合は、`sendEmailNotification`関数のメール送信部分を以下のように変更：

```javascript
// 複数のメールアドレスに送信
const recipients = [
  'kaori.deguchi@unlimitedenergy.co.jp',
  'support@unlimitedenergy.co.jp'
].join(',');

GmailApp.sendEmail(
  recipients,  // カンマ区切りで複数のアドレス
  subject,
  plainBody,
  {
    htmlBody: htmlBody,
    name: 'Unlimited Energy お問い合わせフォーム'
  }
);
```

### メールのスタイルをカスタマイズする場合
`htmlBody`変数内のCSSスタイルを編集することで、色やレイアウトを変更できます。

## ⚠️ トラブルシューティング

### メールが届かない場合
1. **迷惑メールフォルダを確認**
   - Gmailの場合、迷惑メールに分類されている可能性があります
   - 送信者を連絡先に追加することで解決できます

2. **Apps Scriptの実行ログを確認**
   - Apps Scriptエディタで「実行数」→「実行ログ」を確認
   - エラーメッセージがないかチェック

3. **Gmail送信制限を確認**
   - 1日あたりの送信可能数に制限があります
   - 通常のGoogleアカウント: 1日100通まで
   - Google Workspace: 1日2000通まで

### HTMLメールが正しく表示されない場合
- メールクライアントによってはHTMLの表示が制限される場合があります
- その場合でも、プレーンテキスト版が自動的に表示されます

## 📊 運用のベストプラクティス

1. **定期的なテスト**: 月に1回程度、テスト送信を行い正常動作を確認
2. **スプレッドシートの整理**: 定期的に古いデータをアーカイブ
3. **テンプレート返信の準備**: よくある問い合わせへの返信テンプレートを用意
4. **対応状況の管理**: スプレッドシートに「対応状況」列を追加して管理
