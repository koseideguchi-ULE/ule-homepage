# アンリミティッドエナジー合同会社 ホームページ仕様書

## 1. プロジェクト概要（Why & Who）

### 1.1 制作目的

本ホームページは、以下の3つの主要目的を達成するために制作します：

1. **集客・新規顧客獲得**
   - スタートアップ企業（特にシリーズA前後以降）からの問い合わせ獲得
   - 研究機関・大学からのバックオフィス支援・補助金支援の依頼獲得
   - 学会・国際会議運営サポートの案件獲得

2. **ブランディング・信頼性の確立**
   - 「困ったときに真っ先に思い出してもらえる存在」としてのポジショニング確立
   - 専門性と実績の可視化による信頼感の醸成
   - 「なんとかしてくれる」パートナーとしてのブランドイメージ構築

3. **サービス理解の促進**
   - 複雑なバックオフィス業務を分かりやすく説明
   - 料金体系の透明化による問い合わせハードルの低減
   - 具体的な実績提示による導入イメージの明確化

### 1.2 ターゲット（ペルソナ）

#### ペルソナ1: スタートアップ経営者・COO
- **属性**: 30-45歳、IT/バイオ/研究開発系スタートアップ、シリーズA〜B調達済み
- **課題**: 本業に集中したいが、バックオフィス業務（総務・経理・労務）が煩雑
- **ニーズ**: 仕組みから設計してくれる専門家チーム、柔軟な契約形態
- **判断基準**: 専門性、実績、コストパフォーマンス

#### ペルソナ2: 大学・研究機関の研究者・事務担当者
- **属性**: 35-60歳、京都大学・早稲田大学などの研究機関
- **課題**: AMED/NEDOなどの大型補助金の事務処理が複雑で手間がかかる
- **ニーズ**: 補助金申請後の経理管理・報告書作成支援
- **判断基準**: 補助金実績、専門知識、対応の丁寧さ

#### ペルソナ3: 学会・国際会議主催者
- **属性**: 40-65歳、学術団体の理事・事務局長
- **課題**: 年1回の大規模イベント運営に多大なリソースが必要
- **ニーズ**: 参加者管理、海外対応、会場手配などの包括的サポート
- **判断基準**: 国際会議の運営実績、多言語対応能力

### 2.2 ワイヤーフレーム（画面設計）

#### トップページ構成

1. **ヘッダー**
   - ロゴ（左上）
   - グローバルナビゲーション（サービス / 料金 / 事例 / 会社情報 / FAQ / お問い合わせ）
   - CTAボタン「無料相談はこちら」（右上、目立つ配色）

2. **ファーストビュー**
   - キャッチコピー: 「なんとかしてくれる」を、仕事で実現する。
   - サブコピー: 本業に集中できる環境を、バックオフィス支援で創出
   - メインビジュアル: プロフェッショナルな雰囲気の画像（チームワーク、オフィス風景）
   - CTAボタン: 「サービスを見る」「無料で相談する」

3. **サービス概要セクション**
   - 見出し: アンリミティッドエナジーができること
   - 4つのサービスをカード形式で表示
     - アイコン + サービス名 + 簡潔な説明文（各50文字程度）
     - 「詳しく見る」リンク

4. **選ばれる理由セクション**
   - 見出し: なぜアンリミティッドエナジーが選ばれるのか
   - 3つの強み
     1. 専門家チーム体制（窓口は1人、バックには専門チーム）
     2. 業務単位での柔軟な委託（人員管理・教育不要）
     3. 仕組みからの並走（ワークフロー設計から対応）
   - 各項目にアイコンと説明文

5. **導入実績セクション**
   - 見出し: 導入実績
   - ロゴまたはカードで実績表示
     - 「スタートアップ企業 バックオフィス構築」
     - 「国際ゲーム理論会議2024 運営支援」
     - 「AMED/NEDO補助金 事務局支援」
   - 「事例を見る」CTAボタン

6. **料金プランセクション**
   - 見出し: 明確な料金体系
   - 3つのプランを横並びで比較表示
     - ライト / スタンダード / プレミアム
     - 価格、時間、適した用途を明記
   - 「詳しい料金を見る」リンク

7. **CTAセクション**
   - 見出し: まずはお気軽にご相談ください
   - 説明文: 初回相談は無料です。貴社の課題をお聞かせください。
   - 大きなCTAボタン: 「無料相談を申し込む」
   - 電話番号・メールアドレス表示（任意）

8. **フッター**
   - 会社ロゴ
   - サイトマップリンク
   - プライバシーポリシー、利用規約
   - 著作権表記
   - SNSアイコン（LinkedIn、Twitter/X など）

#### サービス詳細ページ構成

1. サービス名 + キービジュアル
2. サービス概要（200文字程度）
3. こんな課題を解決します（箇条書き）
4. 具体的なサービス内容（詳細説明）
5. 導入の流れ（ステップ図）
6. 料金プラン案内
7. 関連事例へのリンク
8. CTAセクション

#### 料金プランページ構成

1. 料金プラン比較表（詳細版）
2. 各プランの詳細説明
3. オプションサービス一覧
4. よくある質問（料金関連）
5. 見積もり依頼CTAボタン

#### 導入事例ページ構成

1. 事例一覧（カード形式、フィルター機能付き）
2. 各事例詳細
   - クライアント情報（業種、規模）
   - 課題
   - 提供サービス
   - 成果
   - お客様の声（任意）
3. CTAセクション

   - イラストや図解を活用した分かりやすい説明

   - シンプルで洗練されたレイアウト
   - 統一感のあるアイコンデザイン
   - 高品質な画像素材の使用

- 丁寧かつ親しみやすい文体（「です・ます」調）
- 専門用語は分かりやすく説明を付記
- 具体的な数字やデータを積極的に使用
- お客様目線での課題解決を強調

**各ページ共通ルール**

  - 例: 「本業に集中できる環境を創出。総務・経理・労務などのバックオフィス業務を専門チームが支援します。スタートアップから研究機関まで、柔軟な料金プランでサポート。」
- **OGP設定**: FacebookやTwitterでのシェア時の表示最適化

## 7. リスク・注意事項

### 7.1 想定リスクと対策

1. **スケジュール遅延リスク**
   - **原因**: 素材提供の遅れ、仕様変更、確認作業の遅延
   - **対策**: 各フェーズで明確な期限設定、定期的な進捗確認ミーティング

2. **コンテンツ不足リスク**
   - **原因**: 導入事例が少ない、実績が公開できない
   - **対策**: 初期は汎用的な説明で構成、実績追加を見越した拡張可能な設計

3. **SEO効果が出ないリスク**
   - **原因**: 競合が強い、コンテンツ量が少ない
   - **対策**: ブログ機能で継続的なコンテンツ追加、ロングテールキーワード戦略

4. **セキュリティリスク**
   - **原因**: WordPressの脆弱性、プラグインの脆弱性
   - **対策**: 定期的なアップデート、セキュリティプラグイン導入、定期バックアップ
